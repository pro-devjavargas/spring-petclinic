# 04. Bitácora de Uso de IA

## 1. Herramientas Utilizadas
- **Modelos de lenguaje avanzados** para asistencia en refactorización, estructuración de DTOs y resolución de incidencias en pruebas.

## 2. Objetivos de Uso
- **Análisis de código:** Identificación rápida de puntos de acoplamiento en controladores legacy.
- **Generación de contratos REST:** Estructuración limpia de clases DTO y anotaciones de Bean Validation.
- **Sugerencias de pruebas:** Refactorización de pruebas de controladores (`OwnerControllerTests`).

## 3. Verificación Humana
- Todo el código generado por IA fue revisado línea por línea, adaptado a las convenciones de Spring Boot 4 / Java 21, compilado localmente y validado mediante la ejecución exitosa de 78 pruebas unitarias y de controladores.
